# Проверка frontend-демо

Текущая версия развивает codex/mock-app-cycle и использует реальную маршрутную навигацию, shadcn/ui и слои по приложенному rules.md. Backend, SSO и LLM для демонстрации не нужны.

## Запуск

Из корня: `pnpm install --frozen-lockfile`, затем `pnpm --filter @alfa/frontend dev`. Frontend слушает порт 3000. Node 24.19.0, pnpm 11.25.0.

## Основной путь

1. Прямой вход в сводку «Север Металл», финансовый директор. Первое событие о ставке связано с кредитной нагрузкой.
2. Открыть разбор, затем «Источники», «Ход анализа» и «Вопросы». В учебном диалоге проверить риски или следующий шаг; неподдержанный вопрос не получает вымышленный точный ответ.
3. Сохранить событие, оценить полезность и оставить замечание. Оценка и текст независимы. Reload сохраняет их в этом браузере.
4. Через switcher выбрать «Город Маркет»: изменятся порядок и объяснения; прежние saved/chats не покажутся. Для Север Металл смена CFO на CEO меняет первый приоритет со ставки на энергию.
5. Проверить фильтр, поиск (также Ctrl/Cmd+K) и TXT-экспорт текущего набора.
6. «Обновить сводку»: фазы и Cancel. Отмена/переход на другой экран записываются в историю исходного scope, новый результат не публикуется.
7. «Сценарии демо»: partial/empty/error/budget/denied; обычный запуск восстанавливает сводку.
8. Прямая ссылка `/?insight=rate`, reload, back, Escape и возврат фокуса. Mobile navigation и выбор компании работают из Sidebar.

## Границы

Данные и ответы синтетические, не банковская аналитика. Fixture date — 21 октября 2026; время запусков фактическое, показывается в МСК. Local storage — UX-персистентность, не авторизация. Не вводить реальные клиентские данные. История до 50 записей; диалог до 20 ответов на событие и scope.

`src/entities` описывает данные/состояние; `src/blocks` — сценарии; `src/pages` — композицию. `src/app` содержит routing/providers/styles, `src/components` — generic UI, `src/shared` — технические helpers. [Подробная архитектура](../../specs/07-frontend-architecture.md).

Проверки: `pnpm --filter @alfa/frontend typecheck`, `test`, `test:e2e`, `build`. Съемка: `pnpm --filter @alfa/frontend screenshots` при запущенном frontend. Параметр системного Chromium и инструкции — в [README](../../README.md).

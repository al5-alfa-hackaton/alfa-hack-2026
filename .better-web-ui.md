## Design Context

### Users

Руководители и финансовые директора крупного бизнеса. Ежедневно просматривают события, проверяют влияние на компанию и первоисточники. Основной сценарий: лента → разбор → источники → уточнение. Desktop для чтения, mobile для быстрого просмотра.

### Brand Personality

Спокойный, точный, деловой. Альфа Бизнес: красный знак и один основной акцент действия. Учебные данные всегда обозначаются как демо; позиция банка отделяется от AI-интерпретации.

### Aesthetic Direction

Taste Skill: framed-sheet, seed 2099893729. Нейтральная рамка, белое рабочее полотно, небольшие заголовки, выразительная типографика Manrope с кириллицей, компактные строки событий. Светлая тема по умолчанию, нейтральная тёмная. Собственный элемент продукта — «Почему для вас»: событие связано с конкретным признаком компании. Без фиолетовых панелей, неоновых статусов, KPI ради украшения и маркетингового вступления.

### Implementation Defaults

Обнаруженный стек: React 19 / TanStack Start / Router / Tailwind 4 / shadcn/ui. Существующие Radix-примитивы сохраняются; combobox использует Base UI. Sidebar, Sheet, Tabs, Dropdown Menu, Accordion, Table, Empty, Alert и Sonner — готовые локальные компоненты. Простые формы используют нативный submit и компоненты полей; React Hook Form уже установлен для сложных форм. Маленькие списки без виртуализации. Source of truth shadcn: projects/frontend/components.json. Архитектура из приложенного rules.md: app → pages → blocks → components → entities → shared. Существующий стек имеет приоритет над fallback-рекомендациями навыков.

### Design Principles

1. Сначала влияние на бизнес и его основание; служебные статусы тише содержания.
2. Один основной акцент действия, цвет риска только там, где есть риск. Выделение компании/роли нейтральное.
3. Стандартные компоненты управляют фокусом, клавиатурой, модальными поверхностями и навигацией.
4. Реальное действие с каждой кнопки; пустое состояние предлагает выход, ошибка — восстановление.
5. Демо не маскируется под банковскую интеграцию. Избранное, диалоги и история строго изолированы по компании и роли.

## Принятые решения

- pnpm workspaces; приложения в `Projects/frontend` и `Projects/backend`.
- TypeScript, React, **TanStack Start** (так интерпретировано название «Tenstec Start»), shadcn/ui и Tailwind CSS.
- Fastify, Drizzle ORM, PostgreSQL. Предметная схема сейчас пустая.
- Для долгих агентных запусков рекомендуются BullMQ + Redis и отдельный процесс воркера в пакете backend; сейчас не реализованы.
- `Research/` зарезервирована под исследование skills, AGENTS.md/agent-команд и MCP-инструментов, сейчас пустая.

## Ограничение выбора harness

Под «OpenCoda» предварительно понимается OpenCode; точное средство еще не выбрано. На с. 18 PDF запрещены внешние автономные AI-агенты и готовые мультиагентные системы **в качестве основного компонента решения**. Готовый harness нельзя заранее считать допустимым. Основной вариант — собственный цикл планирования, поиска, анализа, ранжирования и проверки на разрешенных LLM. Внешняя оболочка возможна только после проверки ее роли и согласования трактовки с организаторами; детали в [04-agent-runtime.md](04-agent-runtime.md).

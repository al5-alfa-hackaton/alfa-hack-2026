# Рабочее пространство через API, без SSO

> Текущие SQL-аккаунты, вход по паролю, регистрация компании и структура packages описаны в [13-accounts-and-packages.md](13-accounts-and-packages.md). Описание входа по ключу ниже относится к предыдущему этапу; token остаётся для сервисных клиентов.


Актуальный контур от 22 октября 2026. Заменяет описания browser demo и отдельной вкладки сервиса в предыдущих документах.

## Интерфейс

Все основные маршруты читают Fastify: лента, сохранённое, профиль, история, разбор, документы, журнал агента, вопросы и обратная связь. Удалены вымышленные профили Север Металл/Город Маркет, сценарные ответы, таймеры прогресса и меню демонстрационных сценариев. Ошибка API показывает ошибку и повтор, без fallback на fixtures.

TanStack Query отвечает за server cache, AbortSignal, invalidation и polling. Компания и ракурс — единственные предпочтения в sessionStorage, отдельно для каждого пользователя и с проверкой доступных серверных компаний. Сохранения, оценки, замечания, сообщения и история находятся в PostgreSQL. Ключ доступа не сохраняется в browser storage. Выход очищает query cache.

При обновлении сводки запускается POST analysis-runs с Idempotency-Key. Повтор после сетевого сбоя использует прежний ключ. Пока исход неизвестен, состояние сверяется с историей. Активный run находится после reload; уход со страницы его не отменяет. Polling активного задания — 1 с, истории в простое — 15 с. Отмена явная. Предыдущая сводка остаётся до публикации новой. Время показывается по Europe/Moscow; нет искусственных процентов выполнения.

Deep link использует UUID insight. GET detail позволяет открыть сохранённую старую версию, которая уже не входит в текущую сводку. Факты, выводы AI, оговорки и позиция банка отображаются раздельно. Источники загружаются через авторизованный documents API, PDF — через защищённое изображение страницы. TXT-экспорт включает только отфильтрованные загруженные события, реальные даты, цитаты и ограничения.

## Вход без SSO

POST /v1/session обменивает ключ из AUTH_USERS_JSON на подписанную HttpOnly cookie alfa_session со сроком 8 часов. SameSite=Strict, Path=/, Secure в production. DELETE /v1/session удаляет cookie. Bearer API остаётся для сервисных клиентов. Cookie содержит только user ID и срок; memberships берутся из текущей server configuration на каждом запросе.

Подпись зависит от настроенных аккаунтов: смена ключей инвалидирует прежние сессии. Отдельного хранилища сессий и индивидуального server-side logout/revocation нет; украденная cookie действует до истечения срока или ротации конфигурации. HTTPS обязателен для production. Cookie-мутации и login/logout проверяют Origin при его наличии; SameSite защищает browser-запросы без Origin. CORS_ORIGIN должен совпадать с публичным origin frontend. Прокси сохраняет Cookie/Set-Cookie. Login ограничен 10 запросами/минуту/IP; API — 600/минуту/аккаунт. Это стартовые эксплуатационные параметры, не нагрузочное SLA.

Авторизация и выбранный аналитический ракурс независимы. Нет регистрации, самостоятельного назначения компаний, корпоративного SSO или SQL membership administration. Выдача/ротация ключей — действие администратора. Локальный scripts/create-access.py проверяет CLIENT в CSV, добавляет аккаунт, сохраняет случайный ключ в игнорируемую .local/ с правами 0600.

## Реальные данные и конфигурация

Ссылки извлечены из аннотаций исходного PDF: страница 15 — CSV, страница 17 — материалы банка. scripts/fetch-data.py скачивает 3 CSV и 9 PDF, проверяет опубликованные размеры и записывает SHA-256 manifest. data/raw и data/processed не попадают в Git.

В этой среде загружены 85 525 строк компаний, 9 PDF/64 страницы и 1 037 RSS-публикаций из 7 доступных источников. ТАСС вернул 503, ответ Банки.ру не распарсился. Все PDF — сканы без текстового слоя. Локальный Tesseract rus+eng дал 193 фрагмента после повторного ingest; OCR может ошибаться, для проверки доступна исходная страница. Это проверка ingestion, не экспертная оценка качества.

AGENT_PROVIDER по умолчанию disabled: профиль и имеющиеся результаты доступны, новые задания отклоняются до создания записи/резервирования бюджета. GET /v1/me содержит analysisAvailable. Чтобы включить LangGraph, нужны DATA_DIR, одобренный LLM gateway/key и подтверждённый hard per-request RUB cap. При неверной конфигурации нет автоматического переключения на fixtures. Модульные тесты NODE_ENV=test используют fixture provider; за пределами тестов он включается только явно. Production запрещает fixtures и DEV_AUTH. Старые fixture insights не выдаются в режиме research.

Новые точки входа входят в OpenAPI; frontend использует generated operations. Корпус загружается при старте. Новости worker обновляет по расписанию `NEWS_REFRESH_CRON`, и API и worker перечитывают их без перезапуска. Материалы банка и CSV по-прежнему требуют перезапуска.

## Проверки

Офлайн: frontend transport/unknown values, backend session signature/expiry/scope/Origin/bearer, agent/ranking/evidence tests. Интеграция PostgreSQL/Redis с настоящим worker: 14 проверок. Playwright проверяет вход/выход, SQL persistence, поиск/экспорт, scopes, deep links/источники, вопросы/оценки, историю, ranking, API failure/retry, mobile и часть WCAG через axe. E2E используют отдельный аккаунт и явный fixture provider; платные LLM не вызываются.

# Данные, семантика и хранение

Источник: `packages/agent/src/data/*`, `src/tools/functions.ts`, README исследования и зафиксированные ответы организаторов. Набор повторно скачан по ссылкам из PDF; исходники и обработанные данные вне Git. Проверены 85 525 строк, 9 PDF/64 страницы, 1 037 RSS-публикаций; локальный OCR дал 193 фрагмента. Подробнее — [12-product-workspace.md](12-product-workspace.md).

## Проверенная семантика

| Поле/набор                                | Правило реализации                                                                                        |
| ----------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| `REVENUE_COMPANY`                         | 2025 год, рубли. `1000` — заглушка, преобразуется в null                                                  |
| `CL_TYPE`                                 | CLI допускает анализ только CLIENT. Prospect/Close Client могут быть контрагентами                        |
| `GROUP_ID`                                | Объединение группы. Известная суммарная выручка дает оценку масштаба, но не доказывает сегмент банка      |
| Неполная выручка группы                   | Нижняя оценка; сохранять число участников без выручки и предупреждение                                    |
| `FTS_FLAG`, `FTS_COUNTRY_NAME`            | Наличие записей ФТС и страны. Экспорт/импорт, валюта, объемы и доли неизвестны                            |
| Продукты `CL_PRODUCT_*`, `FACTORING_MARK` | Только Альфа-Банк; продукты других банков, сумма долга и тип ставки неизвестны                            |
| `NEGATIVEMARK`                            | В текущем парсере `keyOwnerMark`; не негативный кредитный риск                                            |
| Synthetic ID                              | Строковые обезличенные идентификаторы, не реальные названия компаний/людей                                |
| Платежи                                   | Рубли с 1 января текущего года, только видимые Альфа-Банку; payer → beneficiary                           |
| Самоплатежи                               | Исключаются из концентрации/долей, возвращаются отдельно                                                  |
| Отрасли контрагентов                      | Если объем без известных профилей >50%, `industriesReliable=false`; не характеризовать по ним весь бизнес |
| Общие физлица                             | Сигнал аффилированности, не доказательство контроля                                                       |

Исследование: 85 525 строк компаний, 85 514 ID; U_428697 встречается 12 раз. CLIENT — 41 968 ID. Заглушка выручки — 599 строк. По известной индивидуальной выручке >=15 млрд — 115 юрлиц, по групповой — 13 601 клиент. Порог не предоставляет доступ и не присваивает сегмент автоматически.

`pickRow` сейчас выбирает строку с максимальной известной выручкой и сообщает число дублей. Для production нужна явная политика конфликтов с row provenance; не скрывать расхождения.

## CSV

- `df_Uid_data_hack.csv`: ID/группа, ОКВЭД, собственность, возраст/стадия, градации сотрудников, продукты, ФТС, выручка, город/регион. `ORG_TYPE` есть в PDF, но текущий тип Company его не сохраняет: решить необходимость отдельно.
- `df_Fid_Uid_link_hack.csv`: synthetic person/company IDs и география. Не таблица аккаунтов пользователей.
- `df_Uid_payment_hack.csv`: PAYER, BENEFICIARY, PAY_AMT, PAY_CNT.

Null/false/0 различаются. ОКВЭД/ID — строки. Production: SQL numeric и decimal string с валютой/периодом в JSON. Research использует JS number; проверить большие агрегаты при переносе.

## Корпус

RSS — в основном заголовок и лид, полный текст бывает у РБК. `news:fulltext` в `packages/agent` дополняет текст со страницы статьи (`textSource: 'article'`): на 23.10 полный текст у 1521 из 1603 новостей. Общие ленты РИА Новости и ТАСС исключены как малополезные для бизнеса. Ссылки на другие материалы и реклама источника вырезаются из текста (`trimArticleText`). Новости о боевых действиях, атаках БПЛА, СВО и войнах (`isWarNews`) не выдаются поиском агента и попадают в ленту, только если прямо задевают отрасль компании. Search snippet (400 символов) не доказывает полноту. DTO должен содержать `contentExtent=title_only|lead|full`, published/fetched/updated timestamps. Текущий dedup использует URL hash и нормализованный заголовок. Отбор `rankNewsForCompany` объединяет сообщения разных источников об одном событии (`relevance.relatedNewsIds`); хранение всех source links в DTO еще нужно.

PDF банка — преимущественно сканы. OCR передает подписанные значения, не восстанавливает неподписанные точки графиков. Сохранять document/page IDs, hash оригинала и страницы, OCR model/prompt version, качество и возможность ручной сверки.

Прогноз ставки на конец 2026 менялся: июль — 13,5%, с 11 сентября — 14,0%. Это сведения корпуса, не автоматически актуальный прогноз сегодня. Отчет о стали 2021 года помечен историческим. Выбор позиции банка учитывает дату и редакцию; нельзя усреднять противоречащие прогнозы.
